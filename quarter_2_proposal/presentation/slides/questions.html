RESEARCH QUESTIONS

The questions we aim to resolve

01

Does the correction help?

Measure agreement with held-out nonlinear CGYRO by plasma regime, and find out why it gets worse where it does.

02

Does uncertainty predict error?

Test whether the 5–95% interval width tracks error against CGYRO, and whether it can set α for each case.

03

How much CGYRO is enough?

Retrain on growing subsets of CGYRO cases to see when the correction reliably improves predictions.

METRICS

Median MAE, 5–95% coverage and interval width

TEST SPLITS

In-range vs out-of-range cases; discharges held out together

BASELINES FOR α

None, one fixed value, one per channel, learned

We report error and interval width for both the uncorrected surrogate and the corrected model, so we can tell real improvement apart from just falling back to TGLF. The base surrogate is checked against held-out TGLF; the corrected model against held-out CGYRO. Open design choices (architecture, correction scale such as arcsinh or log ratio, and two-NN vs fine-tuning) are settled on development data.
