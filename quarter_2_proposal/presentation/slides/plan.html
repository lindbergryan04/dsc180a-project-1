DATA AND TIMELINE

Project Timeline

Data in hand

  • 43 nonlinear SAT3 cases with matched TGLF-SAT2 runs
  • 13 additional DIII-D cases
  • ~300 dispersed nonlinear CGYRO cases (access confirmed by Emily Belli)
  • New TGLF runs from random inputs at SDSC

No new nonlinear CGYRO runs are needed.

Weeks 1–2

Audit coverage and compatibility; set scope, splits and tolerances.

Weeks 3–5

Establish TGLF-surrogate accuracy; train matched correction baselines.

Weeks 6–8

Test correction scales and weighting; add isotope-trend and smoothness checks.

Weeks 9–10

Evaluate frozen models; deliver reproducible code and a paper draft.

Deliverables: a fast uncertainty-aware hybrid surrogate, an independent evaluation, and a paper draft.

Main risks: matching physics and normalization between codes, separating noisy nonlinear averages from real discrepancies, and learning a correction that transfers from sparse data. If the correction fails, we investigate coverage, noise, representation and model choice, which is itself a result.
