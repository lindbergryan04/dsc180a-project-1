Heat and Particle Transport surrogates: Leveraging TGLF and nonlinear CGYRO data

We aim to produce a fast and reliable neural-network surrogate model for heat and particle transport trained on TGLF across wide parameter ranges, then correct it toward sparse nonlinear CGYRO and test where that correction transfers.

TRAINED ON BROAD TGLF DATA

Base surrogate Sφ

Predicts the 5th, 50th and 95th percentiles of each flux: a median plus an uncertainty band.

NO PHYSICS CODE AT RUN TIME

Hybrid flux prediction

Ion heat, electron heat and electron particle flux (Qi, Qe, Γe).

F̂c(x) = Sφ,c(x) + αc(x) · Rθ,c(x, Sφ(x)), 0 ≤ αc ≤ 1

Our Q2 project is a two-part hybrid surrogate. First, a neural network trained on lots of cheap TGLF runs that predicts each flux as a 5/50/95 percentile band. Second, a small correction network trained on matched nonlinear CGYRO cases that nudges the TGLF prediction toward CGYRO. Alpha controls how much of that correction we trust in each case. Once trained, it predicts fluxes without running TGLF or CGYRO.

RESEARCH QUESTIONS

The questions we aim to resolve

01

Does the correction help?

Measure agreement with held-out nonlinear CGYRO by plasma regime, and find out why it gets worse where it does.

02

Does uncertainty predict error?

Test whether the 5–95% interval width tracks error against CGYRO, and whether it can set α for each case.

03

How much CGYRO is enough?

Retrain on growing subsets of CGYRO cases to see when the correction reliably improves predictions.

METRICS

Median MAE, 5–95% coverage and interval width

TEST SPLITS

In-range vs out-of-range cases; discharges held out together

BASELINES FOR α

None, one fixed value, one per channel, learned

We report error and interval width for both the uncorrected surrogate and the corrected model, so we can tell real improvement apart from just falling back to TGLF. The base surrogate is checked against held-out TGLF; the corrected model against held-out CGYRO. Open design choices (architecture, correction scale such as arcsinh or log ratio, and two-NN vs fine-tuning) are settled on development data.

Deliverables: a fast uncertainty-aware hybrid surrogate, an independent evaluation, and a paper draft.

Main risks: matching physics and normalization between codes, separating noisy nonlinear averages from real discrepancies, and learning a correction that transfers from sparse data. If the correction fails, we investigate coverage, noise, representation and model choice, which is itself a result.
